# 版本11：时钟证据与实测起音归并

版本11采用浏览器内传统DSP，没有新增模型、训练、音频上传或后端。
对照是版本10提交`b3013cfeb3fe2ae15d4a18689727acca4c639706`。

## 具体变化

- 综合曲线与选中主线只在时钟副本上合并强度，取最大值而非重复相加；原检测值保留。
- 同一次起音的跨频段候选绑定回原选中事件，保留原时间、频段、强度及字段，避免抬高强度分位阈值后挤掉弱拍。
- 局部IOI与去均值相关提出周期假设，动态规划保留完整前驱间隔状态。
- 相位约束须有唯一受支持参考，还必须解释该块所有原选中起音；出现反证或上下文不足时保留原证据。接近原选中起音50ms内的时钟事件不会被归零。
- 起音查询使用已验证等价的时间索引，减少全表扫描及临时数组。下落显示、判定窗口和J2规则不变，谱面版本升为11，旧版最佳成绩分开保存。

完整本地测试449项通过，1项私有歌曲项默认跳过；比较工具12项通过，构建通过。

36个既有PCM控制、旧180段及源码移植等价检查单独保留，不冒充上述新材料。

实际桌面Edge移动视口9个场景通过：原生22050/44100/48000Hz噪声均可恢复拒绝，
24次鼓击后半物理幅度2%时四档各保留24个独立起手，原边界cue保留，
真实触控6秒结算、全屏、暂停/倒计时、竖屏自动暂停均通过。
用户授权《九万字》原生完整解码约232.0602秒，四档生成、指法检查、重复、短播及退出通过；
生成数量不作为该歌曲音乐精度证据，未完成人工逐键听感评审。

本轮108份源码与构建资产前后哈希一致，入口/Worker实际响应体匹配；
160个HTTP请求均为同源GET/200，模型、ONNX、WASM、上传请求为0，页面/console异常为0；
