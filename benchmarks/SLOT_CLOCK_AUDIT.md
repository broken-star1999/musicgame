# SC2 all-slot clock audit: both versions rejected

**SC2-slot/v1 failed its original input interface; the explicit SC2-slot/v2 correction completed the fixed cached experiment and failed the unchanged musical-quality gates. Both source snapshots are inactive research archives. Neither is adopted into the running game.** This is a development-branch evidence archive, not a release, deployment, phone-performance result, or fresh-audio evaluation.

The accepted baseline is `aeaf78284cb66601fd02bf9e40eaf99642285689`; Chart12 and judgment2 are unchanged. The running project remains pure algorithms. The source changes add no neural inference, model weights, model download, remote model service, or audio-upload route.

## Full failures, modes, and retained controls

For each version the JSON includes 36 paired cases, 144 full mode records with raw hit/prediction/reference scores, 144 hold/tail/density/finger records, and 36 four-finger measured-head retention records. It preserves both count ratio and identity rather than treating them as interchangeable.

Corrected minimum four-finger count ratio is **1.000000000**, and minimum measured-head identity within 20ms is **0.919540230**. The count gate passes; that does not erase changes to the physical heads. Counts include unique measured-onset heads according to the saved origin ledger, while the main Head metrics use all deduplicated chart note heads.

Some controls are preserved or improved. The source handoff case has 38 physical primary heads and 38 one-finger heads, all 38 matched at 70ms. The drums-plus-same-noise case has 32 physical primary and one-finger heads, all 32 matched, with Head70 F1 gain 0.01538461538461533. The Disco readout already has 28 physical primary heads and its one-finger chart has 28 predictions, with 17 hits against 62 references at 70ms. Its sparse result is therefore visible before the final one-finger selection count. These facts do not claim that every control regressed or that changing one prior would choose a particular unsaved alternative.

The five historical EC1 frontier-budget failures now have successful corrected SC2 cached Node application returns. The exact case IDs and saved historical error messages are retained in the JSON. This distinguishes resource completion from the still-failed quality judgment; it does not claim phone stability or a fresh-audio pipeline result. Because SC2 also changes fit/loss/path/prior semantics, it is not an isolated causal experiment proving compaction alone caused the absence of those exceptions.

## Mathematical, source, and resource boundaries

The original kernel and validated-path mathematical certificates are reused by exact source identity; they were not rerun for the correction. The corrected readout and bridge have their own first-execution certificates. Every stage's actual report/freeze hash, assertion count, entry budget, and independent/self-reported counter boundary is retained. Passing these finite controls does not certify human tactus or musical quality.

The fitter evaluates all explained source slots on a canonical physical axis with squared residuals. `physicalAxis` is the primitive observation view; `evaluationAxis` preserves the exact doubles that produced assignments. The path declares a six-integer lexicographic objective: physical timing, fitted-period prior distance, original evidence rank, primary resets, source changes, and original rank. Physical timing has priority over the original-period/evidence priors. A source-normalization certificate is not rematching or an identification proof. The archive does not retain every candidate graph for a counterfactual re-optimization claim, and no such re-optimization was run.

The saved first selected Disco owner has fitted P=0.9662732997577457 while the supplied original preferred P=0.4878048780487805 and selected original evidence rank is 12. A fast original preferred value was therefore present. This selected result cannot simply be attributed to a slow supplied prior, and it does not establish the eligibility, score, or winner of an unrecorded alternative. The separate cached causal audit passes 5017 integrity/accounting checks, retaining nine focused cases' scalar role counts, chart membership counts and stored scores. Per-owner time tapes are private and omitted. Its owned-binding loss checks and maximum axis discrepancy do not prove a full eight-second primitive GCD or repeat OLS.

All 31 source files for each patch passed ordinary `git apply --check` and application in a separate ignored baseline tree, with exact byte/inventory correspondence. There are 6 modified existing files, 7 explicit slot-clock additions, and 18 unchanged files; no historical filename aliases. Actual metadata is `Analysis.slotClock` plus serializable `Analysis.arrangementSalience`. The fitter's separate `EC2-source-slot-affine/v1` schema marker remains intentionally unchanged. Full import closure and explicit reuse-map derivations are disclosed in the two unmodified source manifests.

The corrected child took 6.661414900 seconds for this cached Node run, including report work. Sampled maximum RSS was 224038912 bytes. These are sampled process observations, not continuous memory peaks, a whole-process cap, a phone measurement, or isolated fitter latency. V8 old-space budget is 512 MiB; it is not an RSS hard cap. Internal fit/path work is producer self-report. Stored owner bindings do not independently prove the full eight-second primitive GCD or repeat OLS, and the result projection does not run those algorithms.

Head means the one-finger chart's `uniqueHeads`; Clock means `Analysis.rhythm.beats`, which can differ from B's low-support compilation reference grid. Pulse means `uniqueHeads(analysis.pulse?.onsets ?? analysis.onsets)`: the pulse onset pool is preferred, with the original onset pool as fallback. Its labels need not enumerate every reasonable musical subdivision. Raw hit counts, denominators, precision/recall/F1, mode legality, identity, source timing, and confidence are distinct quantities.

The unchanged ledger remains 210 clips, 89 runs, and 89 freezes; this experiment did not expand to 210, fresh, or sealed audio. Both executions used cached original features only: no audio decoder/analyzer, FFT, PCM read, model, matcher rerun, or new reference matching was called by this projection. Error stacks, personal absolute paths, media, PCM, raw features, GT, and event/note/beat/time arrays are excluded from the public numeric file. Scores, counts, hashes, provenance, failures, and both inactive source patches remain.
