## 固定方案

仅使用原有每 2 秒 TempoBlock 的原 preferredPeriod，在其匹配假设中保留 supported 且非 unknown 的最多四个相位。覆盖率为发射分数；以相邻块中点处的相位差构成 `4 × wrappedCycleDifference²` 转移成本。没有可用相位时断开链，不跨未知块传播。前向与后向 DP 计算整链最优路径和竞争路径间隔，唯一状态权重为 1；其余间隔不超过 1e-9 时权重为 0，否则为 `margin/(1+margin)`。这只是工程权重，不是正确率概率。严格大于更新保留首个前驱和首个末状态，精确平局的回溯次序为逆字典序。

参考锚为原 anchor + meanResidual；coverage 限于 [0,1]，锚与残差是有限的绝对秒数，不限于 [0,1]。在原 100 Hz 包络正值处增加相位对齐先验：

`E1 = E0 + r × exp(-0.5 × (nearestLatticeErrorSeconds/0.05)²)`

其余位置精确保留 E0。原包络不修改，正支持集合不增加；原实测事件时间、选源、速度假设、局部周期、相位门控、原单次 DP 的状态与惩罚、V12 尾部边界规则均保留。实际单次 DP 消费同一次 helper 计算出的 E1，跟踪副本不重复调用 helper。原置信度公式改为消费实际 E1；整对象、时间数组和编谱 geometry 的变化分别记录，不能混为一谈。没有新 FFT、模型或音频上传。

## 人工机制与独立算术验证

在固定 120 BPM、40 个弱主拍（强度 .3）完全重复、较强半拍（强度 1）每三次缺一次的实际 trackBeats 控制中，B 在 50/70 ms 都为 **0/40 命中 → C 40/40**，两侧各预测 40 拍。参考时间仅用于测量，未传给相位计算。

两种相位都完整出现的负控制保持 **0/40 → 0/40**，先验为零，完整 clock 与 DP 精确相同；这类节拍层级歧义没有被解决。无块、未知块、完全平局和零包络控制均保持原 DP；正控制核对原 E0、局部假设和实际消费的 helper 结果。

独立 oracle 通过：30 个具名 + 64 个固定种子短链、8 个非法输入，以及独立的 151 块长链解析资源例，共 **103 次 helper 调用、113,584 项断言，零失败、零调用方修改**。短链完整枚举最大实际为 256 条路径；前向、后向、max-marginal 各 618 项，权重 264 项，E1 32,159 帧。25 项严格路径与 76 项唯一最优路径精确比较，5 项数值平局使用调用前已固定的 1e-12 独立最优分数容差。长链只验证解析对称性，不声称穷举。

显式类型数组空间为 `8F+154B` 字节，30,001 帧/151 块实例合计 263,262 B，其中返回 241,367 B、临时 21,895 B；普通对象和运行时另计。oracle 子进程 37.8006 ms，观测峰值 RSS 67,852 KiB。60 秒期限、256 MiB V8 old-space、512 MiB RSS 检查仅在夹具检查点采样，**不是操作系统连续 RSS 硬上限，也不是手机性能或音乐质量证明**。
